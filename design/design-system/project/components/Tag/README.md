# Tag

One or two words of status on a SOLID fill with a white label: `ad-tone-good`, `ad-tone-warn`, `ad-tone-bad`, `ad-tone-live`, `ad-tone-brand`, `ad-tone-neutral`; counts use `ad-tone-flat` with `ad-on-flat`. Never a tint, never alpha. Status colours mean status; do not repeat a coloured tag down every row as decoration.
