# Receipt body font

`Outfit-Regular.ttf` is the static Regular (400) font from the Outfit authors:
https://github.com/Outfitio/Outfit-Fonts/blob/main/fonts/ttf/Outfit-Regular.ttf

The existing `Outfit-OFL.txt` supplies its SIL Open Font License.
The font is embedded in full in receipt PDFs. It does not include the Naira glyph;
only unsupported characters use the existing Space Grotesk Medium font.
The receipt headings retain Space Grotesk Bold.
