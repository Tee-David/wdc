# Logos

The WDC logo and icon, copied from the website's `public/brand/` files. Never redraw them.

- `logo-navy.svg`: the full logo in navy `#000065`, for light grounds (`ad-bg`, `ad-panel`).
- `logo-white.svg`: the full logo in white, for navy and dark grounds (`ad-hero`, dark theme).
- `icon-navy.svg`: the round icon in navy, for the sidebar on light grounds and small marks.
- `icon-white.svg`: the round icon in white, for dark grounds.
- `icon-orange.svg`: the icon in orange `#ff6500`, as a mark only, never behind words.

Each is a single-ink SVG; pick the file for the ground, since `<img>` cannot recolour it.
