# DeckCard

The one thing that needs this person most, on `ad-hero`. Kind and urgency tags, a label (project or number), a title using the full width (`card-title`), one sentence, two or three facts, a "why" line, then DeckActions. Ghost cards peek under it while more wait. Keys: D done, S snooze. Taking an action stamps the card from the pressed button and sends it away by direction; clearing the last card plays confetti.
