# Brand and tool assets

The tool-logo registry is `frontend/lib/logos.ts`; its renderer is `frontend/components/ui/logo-glyph.tsx`. Read the registry for the current set and source rather than copying a dated count or table into documentation.

Use existing official assets and supported Simple Icons marks. When the registry specifies a monogram fallback, preserve that distinction instead of presenting it as an official downloadable logo. Honour asset licensing and do not invent customer associations.

WDC assets live in `frontend/public/`; the shared brand components render the studio mark. Keep SVG geometry, aspect ratio and theme contrast intact. Center glyphs inside their containers without stretching them. Static marketing assets belong in public; managed uploads belong in R2.

For motion work use the installed Motion Studio skill, with the same WDC typography, palette and asset rules. An image used as a generated screenshot asset needs a reproducible committed capture script.
