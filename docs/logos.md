# WDC Tool Logos — availability & sourcing

Registry: `frontend/lib/logos.ts` (72 marks). Renderer: `frontend/components/ui/logo-glyph.tsx`.

- **simple-icons** — official SVG glyph, shown in the brand hex (or tinted mono in the hero carousel).
- **monogram badge** — official-color rounded badge with a monogram, used where the mark is not distributable via simple-icons (Adobe, Canva, LinkedIn, OpenAI, AWS, Azure, Oracle, Ahrefs, SE Ranking, C#).

The 20 intro-animation logos are listed in `INTRO_LOGO_IDS` in the registry.
